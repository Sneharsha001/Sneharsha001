## Featured Projects

<details open>
<summary><b>ARF-RT — Cloud Identity Attack-Path Analysis & CCPF Research</b></summary>

<br/>

A research-oriented **Bayesian reasoning engine for cloud identity attack-path analysis**. It works with privilege-graph inputs and reasons about uncertainty in the viability of identity paths. The active **Context-Conditioned Path Feasibility (CCPF)** research track investigates how operational context can be represented as formal constraints.

| Category | Details |
|:--|:--|
| **Focus** | Cloud identity attack-path analysis, correlated belief structures, probe planning, and context-conditioned feasibility |
| **Technologies** | Python, graph-based analysis, Bayesian reasoning, constraint-satisfaction modelling, automated tests |
| **Research Context** | Evaluates context such as network origin CIDRs, MFA presence, and principal tags as feasibility constraints |
| **Design Boundary** | Replay-oriented research scope; the documented engine does not make live cloud SDK calls |
| **Current Work** | CCPF evaluator validation, semantic checks, independent review, and planning for later integration and evaluation |
| **Repository** | [temporal-context-aware-cloud-identity-attack-paths](https://github.com/Sneharsha001/temporal-context-aware-cloud-identity-attack-paths) |

**Research direction** — The goal is to distinguish paths that are theoretically represented in an identity graph from paths that remain feasible under a specific operational context, while keeping feasibility reasoning separate from Bayesian probability scores.

</details>
