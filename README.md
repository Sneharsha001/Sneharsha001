# 🚀 Featured Projects

<details>
<summary><b>CCPF / ARF-RT — Temporal-Context-Aware Cloud Identity Attack Path Research</b></summary>

Research and implementation work focused on cloud identity attack-path analysis, temporal context, and context-aware exploitability validation.

- Investigating how temporal context influences identity relationships and attack-path feasibility.
- Formalizing context state, continuity, compatibility, and path constraints.
- Building and testing research artifacts with a reproducible test suite.
- Repository: [temporal-context-aware-cloud-identity-attack-paths](https://github.com/Sneharsha001/temporal-context-aware-cloud-identity-attack-paths)

**Focus:** Python · Cloud Security · Identity Attack Paths · Temporal Context · Testing

</details>

<details>
<summary><b>SiteSphere — Construction Project Management SaaS</b></summary>

A SaaS platform designed to support construction project operations and coordination.

- Project creation and progress tracking.
- Daily Progress Reports (DPRs), task assignment, and issue reporting.
- Material requests, supplier quotations, and budget tracking.
- Document management and approval workflows.
- Repository: [SiteSphere](https://github.com/Sneharsha001/SiteSphere)

**Focus:** React · TypeScript · Tailwind CSS · Node.js · Express · MongoDB · JWT · Cloudinary

</details>

<details>
<summary><b>Infralytix — Multi-Cloud Pricing Comparison Engine</b></summary>

A multi-cloud cost comparison project that processes infrastructure requirements and compares services across AWS, Microsoft Azure, and Google Cloud.

- Connects cloud pricing data to a common comparison model.
- Explores concurrency and benchmarking for pricing retrieval.
- Reported benchmark: sequential execution **88.79 seconds** versus concurrent execution **83.21 seconds**, approximately **6.3% faster** in that test.

**Focus:** Python · Asyncio · AWS · Azure · Google Cloud · Pricing Normalization

</details>

<details>
<summary><b>CineVerse AI — AI-Powered Movie Discovery</b></summary>

**Focus:** React · Full-Stack Development · Gemini AI · TMDB API

</details>
